# Character VJ

（立ち絵：ずんずんPJ公式 ずんだもん）

HWサンプラーっていうんですか？ 効果音をポン出しできるやつ、あれみたいな感じで、キャラクター出せたらおもしろいなぁとおもった次第です

画像/GIF（+ 短いSFX）を1〜8へ割り当て、BPM同期で叩けるキャラクターVJ的ななにかです

Vite、TypeScript、PixiJSで動作します

## 素材の割り当て

1. ステージへ画像や効果音をドラッグ＆ドロップすると、全画面の割り当て画面を表示
2. 上の素材を下の `1〜8` へドラッグ＆ドロップして割り当て。画像と効果音は同じ番号に共存
3. `Enter` や `Esc` で現在の割り当てを確定して閉じる

- コントロールパネルの各 `1〜8` へ直接ドラッグ＆ドロップすると、その番号へ即時割り当て
- `IMAGES / SFX` エリアへ複数ファイルを置くと、1から順に割り当て
- `SKIP D&D ASSIGN` を有効にすると、全画面の割り当てを飛ばして自動割り当て（もともと用意してるとき用）
- 効果音付きスロットは割り当て画面で薄い黄色枠を表示してます。割り当て後はコントロールパネルの `SFX VOL` で音量を調整可能

などなど。GIF以外の画像は最適化して軽量表示されます

GIFは本番表示でアニメーション再生し、UIサムネイルや背景の小さいコピーには軽量な静止プレビューを使用します

## キー操作

| 操作                   | 機能                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| `1〜8` / `Numpad 1〜8` | 各キューを発火（画像 + アニメーション + 効果音）                 |
| `1〜8` 長押し          | 1拍ごとに自動発火                                                |
| `Shift + 1〜9`         | 自動発火のラッチ切り替え。最大4つ                                |
| `9` / `Numpad 9`       | 読み込み済み画像をランダムに1.5倍の重力演出で表示                |
| `9` 長押し             | 毎拍ランダムに重力演出                                           |
| `+ / -`                | 全キャラクターの共通サイズを変更                                 |
| `Shift + +/-`          | 現在のキャラクターだけサイズを補正                               |
| `← ↑ → ↓`              | 全キャラクターの共通位置を変更                                   |
| `Shift + 矢印`         | 現在のキャラクターだけ位置を補正                                 |
| `Space`                | タップでBPMを設定                                                |
| `Shift + Space`        | 拍頭を同期                                                       |
| `R`                    | 2小節分を記録し、自動でループ再生                                |
| `Enter`                | 全アニメーション、効果音、自動発火、ラッチ、記録、背景を解除     |
| `Esc`                  | メニューの表示切り替え。素材割り当て中は先に割り当て画面を閉じる |

右下のミニキーボードもクリック操作できます。実キーボードを押すと対応キーが点灯し、画面上の `Shift` は切り替え（トグルモード）で動作します

## 1〜9の演出

`1 POP` / `2 RUSH` / `3 GHOST` / `4 IMPACT` / `5 FLIP` / `6 JUMP` / `7 SPAM` / `8 CHAOS` / `9 GRAVITY`

1〜8は、Shiftで複数表示すると2〜4列に並びます。9はちょっと拡大して飛んでるやつ

## コントロールパネル

- **BPM**: 30〜300。上下は1刻み。小数の直接入力やタップ算出にも対応
- **TAP / SYNC**: `Space` / `Shift + Space` と同じ操作
- **Quantize**: `OFF → 1/8拍 → 1/4拍 → 1拍 → 1小節`
- **Offset**: -300〜300ミリ秒（動画先行の法則かモニターがズレてるとき用）
- **SFX VOL**: 0〜400%、デフォルト100%。再生中にも反映
- **60 FPS LIMIT**: 更新を最大60fpsに制限（めっちゃFPS出ちゃうときの負荷軽減用）
- **SKIP D&D ASSIGN**: 全画面の素材割り当てを飛ばして自動割り当て
- **HIDE BACKGROUND**: 抽象図形と背景模様を非表示にして背景を黒に変更
- **REC**: 2小節分の操作を記録して自動ループ
- **ENABLE MIDI**: Web MIDIを有効化
- **FULLSCREEN**: 全画面表示

## その他の入力

- **ゲームパッド**: 最初の8ボタンをキュー1〜8へ割り当て。長押しの自動発火にも対応
- **MIDI**: ノートオンを1〜8へ循環割り当てし、ベロシティを強さとして使用。ノートオフで長押しを解除
- Web MIDIには安全な接続環境が必要なため、開発時はlocalhostから開いてください

## その他の仕様

- 効果音は割り当て時にデコードし、先頭と末尾の明確な無音を自動で取り除いて再生
- BPMクロックは実時間基準。タップはBPMだけを変更し、同期操作で最初の拍を調整
- 左下に直近8件の操作履歴、右下に直近12秒のBPMグラフを表示
- 前景キャラクター表示中は薄い同キャラクターを背景でも動かし、小さい背景キャラクターを最大24体程度表示
- GIFはWebCodecsの `ImageDecoder` で再生し、非対応環境ではブラウザー標準のGIF表示へ切り替え
- 高解像度画像、残像、背景キャラクター、GIFには縮小キャッシュ、個数上限、必要時更新を適用

## 観客スマホリモート

VJホストの `REMOTE` → `START REMOTE` で1時間のリモートセッションを開始し、`SHOW QR` から観客のスマートフォンをコントローラーとして接続する

操作データはCloudflare STUNで接続経路を見つけ、ホストと各コントローラー間のWebRTC DataChannelで直接送信します

WorkerとDurable Objectは参加認証、権限配布、接続状態、WebRTCシグナリングだけを扱い、操作データは中継しません

TURNとWebSocket中継へのフォールバックはありません。ネットワーク構成やファイアウォールによって直接接続できない端末では操作できません

初期権限ではキュー1〜9だけを許可します。ホストの `AUDIENCE ALLOW` から `TAP / SYNC`、`RECORD`、`CLEAR` を追加できます
